# Lime Profitability Explorer — Documentation Suite

This documentation accompanies the interactive *Lime Profitability Explorer* Shiny application.  
It provides methodological detail, derivations, and interpretive notes for each analytical module.

## Included Files

| File | Description |
|------|--------------|
| `explanation_agronomic.md` | Derivation of yield response models and agronomic interpretation. |
| `explanation_npv.md` | Economic evaluation: net revenue, net present value, and benefit decay. |
| `explanation_mc.md` | Monte Carlo simulations for probabilistic profitability analysis. |
| `explanation_risk.md` | Risk analysis and variance decomposition. |
| `explanation_scaling.md` | Scaling logic and spatial extrapolation of profitability results. |
| `explanation_adoption.md` | Behavioral and economic adoption interpretation. |

All equations are formatted using LaTeX (MathJax compatible).  
Refer to these documents for integration with the Shiny interface under `docs/`.
